Jedi chooses the wrong overload when the parameter is annotated with `type[...]`. With `get_obj(input: type[Foo]) -> FooBuilder` and `get_obj(input: type[Bar]) -> BarBuilder`, when typing `get_obj(Foo).` Jedi suggests methods of both `FooBuilder` and `BarBuilder`, while only `FooBuilder` should be suggested. A `type[X]` parameter accepts class `X` and its subclasses, not instances. Annotation `type`, `Type` or `type[Any]` accepts all classes. With `type[T]` where `T` is TypeVar, the class must satisfy the bounds or one of the constraints of `T`; If `T` has no bounds and no constraints, then all classes are accepted. The `Optional[X]` parameter takes `None` and any value that `X` takes. Container annotations are also checked element by element: with `list[X]`, `Sequence[X]`, `Iterable[X]`, `tuple[X, ...]` or `dict[K, V]`, the argument must be a container of that type and all of its elements (if mapping, including keys and values) must be accepted by the corresponding annotation, for example `list[type[X]]` only accepts lists where all elements are of class `X` or a subclass of `X` (not instance); with `tuple[X, Y]` the argument must have exactly two elements and each element must match the annotation in the same position. Jedi does not need to consider the variance of the generic type.

Jedi should choose overload as a type checker: the first overload where every invocation argument (either by position or by name) matches the annotation will be used, and only if no overload matches will combine the results of all overloads. If an argument, or a value derived from an unpacked argument, can have multiple types (e.g. Union), the annotation must accept all of those types. When parameters receive arguments via `*args` or `**kwargs`, annotations describing each argument are aggregated; Arguments unpacked from a tuple, list, or dict at the call are also counted, including dicts created by a `dict(...)` call in any call form that `dict` supports. These rules also apply when an overloaded function is called via `functools.partial`. If `*args` or `**kwargs` receives no arguments, the overload still matches. The result of function calls without overloading is unchanged from the current one.
